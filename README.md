# Phở Việt — сайт с онлайн-заказом

Заказы с сайта приходят сообщением в Telegram, а на сервере с базой заказов — в раздел для персонала `/staff`
(заказы, статусы, отчёты; см. «Заказы в приложении»).

- **`/`** — главная-обложка: анимированная ночная сцена, главы, хиты, кнопки «Открыть меню» и «Установить приложение».
- **`/menu`** — быстрая страница меню: категории, поиск, корзина, оформление заказа.
- **Приложение (PWA)** — сайт устанавливается на телефон как приложение с иконкой логотипа и открывается сразу на меню.

```
pho-viet/
├── public/          ← сам сайт
│   ├── index.html   ← главная-обложка
│   ├── menu.html    ← страница меню (/menu)
│   ├── menu.js      ← меню, цены и настройки ресторана
│   ├── manifest.webmanifest, sw.js, pwa.js, icons/  ← всё для приложения
│   ├── staff.html, staff.js, staff.css  ← раздел для персонала (/staff)
├── server.js        ← сервер: раздаёт сайт и пересылает заказы в Telegram
├── db.js            ← база заказов (SQLite, включается переменной ORDERS_DB)
├── staff.js         ← раздел для персонала на сервере: вход, заказы, отчёты, сотрудники
├── .env.example     ← образец настроек
└── .env             ← ваши настройки (создать самому, никому не показывать)
```

Нужен только Node.js 18 или новее (https://nodejs.org), для базы заказов — 22.13 или новее (лучше 24).
Ничего устанавливать через npm не нужно.

## Настройка Telegram (5 минут)

1. **Создайте бота.** В Telegram откройте @BotFather → `/newbot` → придумайте имя.
   BotFather пришлёт токен вида `1234567890:AAH...`.
2. **Создайте файл `.env`** рядом с `server.js` (скопируйте `.env.example`) и впишите токен:
   ```
   TELEGRAM_BOT_TOKEN=1234567890:AAH...
   ```
3. **Решите, куда приходят заказы:**
   - лично вам — найдите своего бота в Telegram и нажмите «Старт»;
   - в рабочую группу (удобно, если заказы смотрят несколько человек) — добавьте бота в группу и напишите там любое сообщение.
4. **Узнайте id чата:**
   ```
   node server.js chat-id
   ```
   Команда покажет найденные чаты. Впишите нужный id в `.env`:
   ```
   TELEGRAM_CHAT_ID=123456789
   ```
   Для группы id начинается с минуса — это нормально. Несколько чатов указываются через запятую.
5. **Запустите сайт:**
   ```
   node server.js
   ```
   Откройте http://localhost:3000, оформите тестовый заказ — он придёт в Telegram.

## Что ещё заполнить

В `public/menu.js`, блок `SITE_CONFIG`:
- `phone`, `hours` — общий телефон и часы работы;
- `locations` — рестораны сети (сейчас 5). У каждого: `name` — название точки, `address`, `phone`, `hours` в формате `10:00–22:00`. По часам сайт сам пишет «Открыто до 22:00» / «Откроется в 10:00» по московскому времени, а кнопка «Маршрут» открывает адрес в Яндекс Картах;
- `orderCutoffMin` — за сколько минут до закрытия перестаём принимать заказы (сейчас 30: при часах 10:00–22:00 заказать можно с 10:00 до 21:30);
- `orderHours` у точки — свои часы приёма заказов, если они не совпадают с правилом выше. У Китай-города `orderHours: "10:00–21:30"`: ресторан открыт до 00:00, а заказы на сайте — до 21:30, как у остальных;
- `deliveryFee` — стоимость доставки для заказов дешевле `freeDeliveryFrom` (сейчас 199 ₽ — уточните).

### Часы приёма заказов

- Заказ можно оформить только с открытия точки до закрытия минус `orderCutoffMin` (или в часы `orderHours`, если они заданы), по московскому времени. Сейчас во всех 5 ресторанах — с 10:00 до 21:30.
- Точки, которые сейчас не принимают заказы, в оформлении недоступны; если закрыты все — сайт пишет часы приёма и кнопка заказа неактивна.
- «Сегодня к …» предлагается не раньше чем через час и не позже конца приёма выбранной точки.
- То же самое проверяет сервер (`public/hours.js` — общий код для сайта и сервера), так что обойти правило из браузера нельзя.

### Куда приходят заказы с несколькими ресторанами

- При оформлении гость всегда выбирает ресторан: для самовывоза — где заберёт, для доставки — ближайший, откуда привезут.
- Заказ уходит в чат выбранного ресторана: переменные `TELEGRAM_CHAT_ID_P1` … `TELEGRAM_CHAT_ID_P5` (номер — это `id` точки в `locations`: P1 Патриот, P2 Орбита, P3 Среда, P4 Янтарь, P5 Китай-город).
- Если для точки чат не задан, её заказы уходят в общий чат `TELEGRAM_CHAT_ID` (запасной вариант).

Цены и блюда меняются там же, в списке `MENU`. Сервер берёт цены из этого файла,
поэтому подделать сумму заказа из браузера нельзя. После правки `menu.js` сервер перезапускать не нужно.

Фото блюд лежат в `public/images/<id блюда>.jpg` (взяты со страницы ресторана на Яндекс.Еде).
Чтобы заменить фото, положите свой файл с тем же именем. Для нового блюда достаточно файла `images/<id>.jpg`.

Картинки главной страницы сделаны в Higgsfield и лежат в `public/scene/`:
- `sky-*`, `town-*`, `lotus-*`, `lantern-*` — первый экран (небо с луной и горами, город у реки, кувшинки с лотосами
  на переднем плане) и фонари в стиле кинореализма.
  `-p` — для телефона, `-l` — для компьютера.
- `bowl/` — сборка Фо Бо по шагам: кадры одной чаши (`s0`–`s3`), настоящее фото блюда (`pho.webp`),
  видео с паром из этого же фото (`pho.mp4`, блюдо в нём не меняется) и летящие продукты (`fly-*`).
- `moon-p.webp`, `moon-l.webp` — луна заставки: тот же диск, что на небе первого экрана (для телефона и компьютера).
  Когда сайт загрузился, луна поднимается ровно на своё место в небе (`fx.js`, `skyMoon`), заставка растворяется.
- `ritual/` — глава 3 «Ритуал»: кадры процесса по шагам (`broth`, `wok`, `herbs`, `door`; `-l` — большая
  карточка, `-m` — маленькие), луна за карточками, ветка персика с фонарём и куст цветов поверх рамок.
  В кадрах только процесс и продукты — готовые блюда на сайте показываются настоящими фото.
  Шаги листаются сами раз в 9 секунд (пока глава на экране); вкладки, карточки справа, свайп и кнопка паузы — вручную.

## Персональные данные

- Политика обработки персональных данных — `/privacy` (`public/privacy.html`), текст согласия — `/consent` (`public/consent.html`). Ссылки есть в подвале и в оформлении заказа.
- Галочка согласия в форме обязательна, и сервер тоже не примет заказ без неё.
- Реквизиты оператора (ИП или ООО, ИНН, ОГРН/ОГРНИП, адрес) вписываются в обе страницы — место отмечено комментарием `РЕКВИЗИТЫ ОПЕРАТОРА`.
- Тексты — шаблон: перед запуском рекламы покажите их юристу (уведомление Роскомнадзора, хранение данных в РФ).

## Мобильное приложение

- Установленное приложение открывается с главной `/app`: акции, оценка гостей, рестораны с адресами и статусом, хиты, полезные ссылки.
- На телефоне внизу панель вкладок: Главная · Меню · Акции · Корзина; при прокрутке вниз она прячется, при прокрутке вверх возвращается.
- При запуске и при перезагрузке показывается заставка с логотипом.
- Меню на телефоне: сверху выбор ресторана (адрес и статус), лупа для поиска, «таблетки» категорий, первое блюдо категории — большой карточкой. Выбранный ресторан подставляется в оформление заказа.

### Акции и купоны (`/promo`)

- Список — `SITE_CONFIG.promos` в `public/menu.js`. Виды: `permanent` (постоянные), `event` (мероприятия, поле `date`), `coupon` (купоны с полем `code`).
- `until` — последний день акции: после него карточка скрывается сама. `img` — картинка из папки `images`.
- Купон: `code`, скидка `percent` (процент) или `amount` (рубли), `minTotal` — минимальная сумма блюд. Промокод вводится в оформлении заказа; поле появляется, только если есть действующие купоны. Скидку пересчитывает сервер (`public/coupons.js` — общий код для сайта и сервера), в Telegram приходит строка с промокодом и скидкой.
- `demo: true` — пример: виден только по ссылке `/promo?demo=1`, гостям не показывается, промокод не действует. Сейчас примеры — «Ланч дня», «Вечер вьетнамской кухни» и купон PHO10.

## Работа у нас

- Страница `/jobs` (`public/jobs.html`): соискатель указывает имя, телефон, должность, возраст, ресторан и опыт.
- Заявка уходит в Telegram-чат выбранного ресторана. Если нужен отдельный чат для заявок — создайте группу, добавьте туда бота и задайте на Render переменную `TELEGRAM_CHAT_ID_JOBS` (ID чата бот пишет сам).
- Список должностей — `SITE_CONFIG.jobs.positions` в `public/menu.js`.
- Ссылки на страницу — в подвале и в финале главной. Согласие соискателя — `/consent-job`.

## Превью ссылки

Когда ссылку на сайт отправляют в Telegram, WhatsApp или VK, показывается карточка с фото: `public/og.jpg` (1200×630).
Адрес сайта прописан в тегах `og:url`, `og:image` и `canonical` в `index.html` и `menu.html` —
при переезде на свой домен замените его там и в текстах `privacy.html` и `consent.html`.

## Поиск (Яндекс и Google)

- `public/robots.txt` и `public/sitemap.xml` — что индексировать и список страниц. При переезде на свой домен
  замените адрес и в них.
- Разметка ресторанов (schema.org: 5 точек с адресами, телефоном и часами) вставляется в главную сервером
  из `menu.js` — правьте адреса и часы только там. Адрес сайта для разметки берётся из `PUBLIC_URL`.
- Чтобы поисковики быстрее увидели сайт, добавьте его в Яндекс Вебмастер и Google Search Console и укажите там
  `sitemap.xml`. Проверить разметку можно в «Валидаторе микроразметки» Яндекса.

## Заказы в приложении (раздел для персонала)

На сервере с постоянным диском заказы сохраняются в базу, а владелец и менеджеры ресторанов работают с ними
на странице **`/staff`** — с телефона, планшета на кассе или компьютера (страницу можно установить как приложение).

- **Заказы.** Новые приходят сразу, со звуком и отметкой; по желанию — системное уведомление. Статусы:
  Новый → Принят → Готовится → В пути (доставка) или Готов к выдаче (самовывоз) → Выполнен; «Отменён» — только
  с причиной. В карточке — состав, сумма, промокод, гость, телефон (звонок в одно касание), адрес с маршрутом,
  оплата, комментарий и история: кто и когда менял статус. Поиск по номеру, телефону и имени.
- **Отчёты** за любой период (сегодня, вчера, 7 и 30 дней, месяц, свои даты): выручка по выполненным заказам,
  средний чек, отмены и их причины, заказы в работе, выручка по дням или часам, по ресторанам, доставка
  и самовывоз, оплата, популярные блюда, промокоды. Кнопка «Excel» выгружает заказы за период.
- **Доступ.** Владелец видит все рестораны и добавляет сотрудников (вкладка «Сотрудники»); менеджер видит
  и ведёт заказы только своей точки. Пароли хранятся в виде хэша, после 8 неверных попыток вход закрыт на 15 минут.
- **Telegram** с базой получает только короткое «Новый заказ №… · точка · сумма» со ссылкой на заказ —
  без имени, телефона и адреса гостя. Если база вдруг недоступна, заказ целиком уходит в Telegram, как раньше.

Как включить (на сервере в России: в базе персональные данные гостей, 152-ФЗ):

1. В `.env` укажите путь к файлу базы на постоянном диске: `ORDERS_DB=/var/lib/phoviet/orders.db`
   и адрес сайта `PUBLIC_URL=https://ваш-домен` (для ссылки в уведомлении).
2. Создайте первого владельца: `node server.js staff add <логин> owner Имя` — пароль покажется один раз.
   Менеджеров владелец добавляет на странице «Сотрудники» или командой
   `node server.js staff add <логин> manager p1 Имя` (p1…p5 — рестораны из `menu.js`).
   Новый пароль: `node server.js staff passwd <логин>`, список: `node server.js staff list`.
3. Резервные копии база делает сама — раз в сутки в папку `backups` рядом с базой (или в `ORDERS_BACKUP_DIR`),
   хранятся 14 дней. Копии стоит дополнительно уносить с сервера (например, в S3-хранилище облака).

Без `ORDERS_DB` (например, на Render, где диск стирается при каждом обновлении) всё работает по-старому:
заказ целиком уходит в Telegram, а `/staff` показывает, что раздел ещё не включён.

## Размещение в интернете

Подойдёт любой хостинг, где можно запустить Node.js: VPS (Timeweb, Selectel, REG.RU),
Render, Railway, Amvera и т.п. Загрузите папку целиком, задайте переменные
`TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` (или положите `.env`) и команду запуска `node server.js`.
Порт берётся из переменной `PORT`, если хостинг её задаёт.

Важно: обычный статический хостинг (GitHub Pages, Яндекс Object Storage) не подойдёт —
без `server.js` заказы отправляться не будут.

## Защита

- Токен бота хранится только на сервере и в браузер не попадает.
- Сумма пересчитывается на сервере по `menu.js`.
- С одного IP — не больше 5 заказов за 10 минут.
- Если Telegram недоступен, покупатель видит сообщение с просьбой позвонить, корзина сохраняется.

## Приложение (PWA)

- **Android (Chrome)** и **компьютер (Chrome, Edge)**: на сайте появляется кнопка «Установить приложение» — одно нажатие, и иконка Phở Việt на экране.
- **iPhone (Safari)**: Apple не даёт сайтам показывать системную кнопку, поэтому по нажатию открывается короткая инструкция: «Поделиться» → «На экран „Домой“» → «Добавить».
- Уже установленное приложение открывается сразу на меню (`/menu`) на весь экран, без адресной строки. Корзина и данные доставки запоминаются.
- Без интернета откроется последняя загруженная версия меню; оформить заказ можно только онлайн.

**Важно:** установка работает только на сайте с **HTTPS** (на localhost — тоже). Почти все хостинги дают HTTPS бесплатно.

**После изменений сайта** увеличьте номер в первой строке `public/sw.js` (`pv-v1` → `pv-v2`), чтобы у установленных приложений обновился кэш.

## Подключение Telegram на Render (5 ресторанов)

1. В Telegram откройте @BotFather → `/newbot` → придумайте имя и адрес бота (должен заканчиваться на `bot`). Скопируйте токен.
2. Render → сервис `pho-viet-site` → **Environment** → добавьте `TELEGRAM_BOT_TOKEN` = токен → **Save and deploy**.
   Сайт сам подключит бота (webhook на `/api/tg`).
3. Создайте 5 групп — по одной на ресторан — и добавьте в каждую менеджеров точки и бота.
   Бот напишет в группе её ID. Если не написал (сайт «спал»), отправьте в группу `/id`.
4. Впишите ID в переменные `TELEGRAM_CHAT_ID_P1` … `TELEGRAM_CHAT_ID_P5` (P1 Патриот, P2 Орбита, P3 Среда, P4 Янтарь, P5 Китай-город) → **Save and deploy**.
5. Проверка: команда `/id` в группе покажет «✅ Сюда приходят заказы: …».

Если группа станет супергруппой (Telegram меняет ей ID), заказы всё равно дойдут, а в логах Render появится подсказка с новым ID — обновите переменную.
